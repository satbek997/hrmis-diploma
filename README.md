## 1. Project Overview

HRMIS is a diploma project focused on developing a Human Resource Management Information System with automated KPI calculation, performance analytics, and report generation.

The system aims to help organizations manage employee information, define performance indicators, calculate KPI results, and prepare reports more efficiently.

## 2. Problem Statement

In some organizations, employee performance data is managed using spreadsheets and separate documents. Manual calculations and report preparation can take significant time and may lead to errors.

This project aims to provide a centralized system with configurable KPI rules and transparent performance calculations.

## 3. Project Objectives

- Manage employee information and organizational structure.
- Define configurable KPIs, weights, and target values.
- Calculate employee performance scores automatically.
- Display performance analytics and KPI trends.
- Generate reports in PDF and Excel formats.
- Implement role-based access control.
- Test calculation accuracy, security, and performance.

## 4. Target Users

- **HR Specialists:** Manage employee information, KPI definitions, and reports.
- **Department Managers:** Review employee performance and team results.
- **Employees:** View their own KPI results and performance history.
- **Top Management:** Review organizational performance reports.
- **Administrators:** Manage user roles and system settings.
